## Acceptance Criteria

- [ ] Each of the 6 evidence items has a 16×16 icon (paper, photo, phone, statement, list, video) shown beside its name in the evidence screen and the showdown menu.
- [ ] The evidence screen is a Pokémon-menu style: a bordered list on the left with the "▶" marker, and a bordered description box for the selected item.
- [ ] The fact-check panel is laid out as a bordered question box with a choice menu, matching the dialogue style.
- [ ] The ending screen uses the pixel theme with the player and boss sprites, the evidence score, and "Start new run".
- [ ] A short controls hint ("I evidence, E talk") and an objective line ("Expose the Deputy Director") show in the corner of the floor and update to the next boss after each win.
- [ ] The hint and objective text come from the floor data files, not code.
- [ ] Everything fits 480×320, reads clearly, and works with the keyboard only.
- [ ] A retained screenshot of each screen touched is saved as evidence.

## Implementation Notes

- Icons are generated by the art script (story 007) into the same atlas folder.
- The hint line is a small Label on the floor HUD; hide it while any panel is open.
